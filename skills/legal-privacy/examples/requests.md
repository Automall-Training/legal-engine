# Example requests

Invented firms only. Each line: the request → what the module does.

- "Нужна политика конфиденциальности для сайта Example Courses SRL (Кишинёв), продаём онлайн-курсы в Молдове и
  Румынии" → procedure 1 for the site, both regimes, recipients from the user, notice from M08 with the art. 13
  content, DOCX in the document language, open questions for unknown countries.
- "Verificați DPA-ul furnizorului nostru de CRM" → procedure 2: role, entity and country, art. 28(3) gaps as a list
  of edits; the provider's text is not rewritten.
- "We host on a US cloud and our clients are in Romania — is that allowed?" → procedure 3: adequacy on the task
  date, else SCC and a short transfer assessment; the lawful path first.
- "Клиент просит удалить все его данные" → procedure 5: controller, right, deadline dates computed, retention
  limits checked; a reply drafted, the user sends it.
- "Мы случайно отправили список клиентов не тому адресату" → procedure 6 first: awareness time, 72-hour deadline,
  one question on risk; then the notification draft.
- "Нужно ли нам DPIA для онлайн-школы для детей?" → procedure 4: criteria, children's data, a screening note.
