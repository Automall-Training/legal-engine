# Example requests

Invented firms only. Each line: the request → what the module does.

- "Сделай условия продажи для онлайн-курсов Example Courses SRL, покупатели в Молдове и Румынии" → facts (live or
  recorded, access start), both regimes, checkpoints C1–C14, terms from model M03 in the document language, a list
  for the web developer; the privacy notice handed to `legal-privacy` if it is on.
- "Verificați termenii magazinului nostru online" → audit: checkpoint table with rules and fixes, real tracked
  changes in the user's DOCX, clean copy.
- "Покупатель через 10 дней просит вернуть деньги за записанный курс, доступ уже был" → withdrawal: was the
  prior consent and acknowledgement given and confirmed (C6)? Conditional answer, the deciding fact named; a reply
  drafted, the user sends it.
- "Do we need the new withdrawal button on our Romanian site?" → C7 on the task date, who provides it, what the
  site must show; the sanction from the act in force.
- "Клиент пожаловался в защиту прав потребителей" → complaint: the rule behind each claim, the lawful position, a
  draft reply; the user files it.
