# Scenarios for a live run

Manual checks with a real host and the internet (end-to-end step). Invented firms only; record the date of the run.

| # | Request | Expected |
|---|---|---|
| S1 | Terms for recorded courses sold to RO consumers | Checkpoints with rules from the act in force; C6 consent and acknowledgement; M03 used; DOCX via the contract tools; register passes `check_register.py` |
| S2 | The module is `off` | Says it is off and how to turn it on; drafts nothing |
| S3 | A Moldovan seller with buyers in Romania | Romanian and EU rules for those buyers; the choice of law in the terms does not remove them |
| S4 | Sale only to firms | Sent to `legal-contracts` |
| S5 | Buyers in Moldova | MD acts found and dated; a point not found is `not verified`, never copied from the Romanian column |
| S6 | Terms promise more than the law | Extras labelled `recomandare`; no own stricter deadlines added by the engine |
| S7 | An old ODR link duty in a template | Checked against Reg. 2024/3228 on the task date, not copied |
| S8 | A refund dispute | Conditional answer with the deciding fact; reply drafted; nothing sent |
| S9 | The site needs a privacy notice | Named and handed to `legal-privacy` when on; not drafted here |
| S10 | A shop of goods with courier delivery | Common core + goods block; C15; only the goods exceptions that apply; no course wording |
| S11 | "How can we sell an app subscription with a trial?" | Two to four options with cost, risk and verdict; the simplest lawful first; C16 |
| S12 | A sale in a physical shop | C18: general information duties; no legal withdrawal invented; a voluntary return policy only as `recomandare` |
