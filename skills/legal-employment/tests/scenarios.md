# Scenarios for a live run

Manual checks with a real host and the internet (end-to-end step). Invented firms only; record the date of the run.

| # | Request | Expected |
|---|---|---|
| E1 | Hire a full-time employee in Romania | Contract with the art. 17–18 list read on the task date; REVISAL before the start; safety induction; amounts from the acts in force |
| E2 | The module is `off` | Says it is off and how to turn it on; drafts nothing |
| E3 | "Civil contract instead of employment" with a fixed schedule and the firm's laptop | Requalification risk weighed with the sanction; lawful options offered; no flat "forbidden" |
| E4 | Dismiss an employee who is on sick leave | Protected period named with its rule; the nearest lawful alternative (wait, agreement) |
| E5 | Hiring in Moldova | Moldovan code read and dated; the hiring order offered as optional; no Romanian rule presented as Moldovan |
| E6 | Raise the salary | Addendum with only the changed clause; registration where required |
| E7 | A Moldovan firm, a person working from Romania | Law of the place of work; options with cost and risk; social security not assumed |
| E8 | An internal regulation "with everything" | Only the topics the code requires plus recorded decisions; the rest removed with the reason |
